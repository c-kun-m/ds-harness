# K00–K13 插件内核完整课程

本目录把 Cordis 与 DSH Scope 的核心拆成 14 个可独立验收的课时。每课都先给功能和失败场景，再让你实现；源码只在你完成第一版后用于复盘。

## 开始前

1. 阅读上一级 [03 总路线](../03-工程骨架与插件内核.md)；
2. 阅读 [统一验收标准](../课程使用说明与验收标准.md)；
3. 确认 `deepseek-harness` 固定提交；
4. 不要把课程文档中的类型名称当成必须照搬的内部结构。

## 课时顺序

严格按 K00 → K13。K01 的简单栈可以独立存在，但从 K04 开始要建立真正的 Fiber/Effect owner，不要无限扩展热身类。

## 每课固定产出

- 一页自己的设计记录；
- 一张状态/所有权/序列图；
- 功能合同对应的黑盒测试；
- 实现；
- `PARITY.md` 条目；
- 一次独立 Git commit；
- 课末问题的书面答案。

## 源码阅读边界

先读课程，再写测试和第一版，最后按每课的“源码复盘”读取固定上游。课程不会提供可复制的最终实现代码。

## 总体毕业作品

一个可通过插件声明依赖、注册服务和事件、创建子插件、更新配置、HMR 替换、按 Scope 隔离资源，并能在任意失败/取消/重入卸载点完全停稳的同进程运行内核。
