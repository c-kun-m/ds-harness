# 04：核心类型、身份、JSON 与跨模块错误

## 本课定位

03 的错误只服务插件内核；本课建立整个 Agent Runtime 共用的 wire-safe 类型。完成前不要写 Session/LLM/Tool 业务，否则不同模块会各自发明 ID、内容块、取消和错误。

上游复刻范围：品牌身份、LLM/Session/Agent 的共享词汇、稳定失败分类。Ontology 的身份在此定义类型，但语义由 13–15 拥有。

## 学习目标

- 防止不同领域 ID 在编译期混用；
- 对所有持久/协议值执行 lossless JSON 校验；
- 建立可扩展但不含供应商细节的内容块与消息类型；
- 区分失败、取消、超时、不确定副作用和完整性错误；
- 用绝对 deadline 向下传播预算；
- 确定对象在同进程借用、日志快照和 wire 传输时的复制/冻结规则。

## 公共类型合同

### 身份

至少定义：

- SessionId、SessionSeq、SessionLogOffset；
- MessageId、TurnId/TurnSeq、StepId/StepSeq；
- ToolName、ToolCallId；
- AgentId、JobId、SubagentId、WorkflowRunId；
- OntologyVersionId、FactId、ActionId、PlanId、ExecutionId。

SessionSeq 与 SessionLogOffset 必须是不同 brand：前者是事件身份，后者是后缀读取边界，不能因当前都用 number 就混用。

### JSON

`JsonValue` 只允许 null、boolean、有限 number、string、array、plain object。边界必须拒绝：

- undefined、BigInt、Symbol、函数；
- NaN/Infinity/-Infinity；
- 循环引用；
- 稀疏数组和会在 JSON.stringify 时偷偷变成 null 的值；
- 自定义 `toJSON` 导致的有损/带副作用变换（策略要明确）。

### 内容与消息

核心内容块至少支持文本、reasoning、tool-call。图片/附件可以作为已验证引用加入，但不能把 base64 大对象无界复制进 Session。消息身份与 source 归属不可变。

不要把 `tool-result` 同时做成普通 assistant 内容和独立 Session surface 消息；05 会固定权威投影。

### 终止与使用量

区分：模型 finish reason、Agent Turn end reason、工具结果状态。它们不是同一个枚举。`max-tokens` 可以是模型正常终止原因，但通常会使自动 Goal Round 停止；`aborted` 也不能伪装成 provider error。

## 错误目录

| 大类 | 例子 | 默认处理 |
|---|---|---|
| CONFIG/CONTRACT | 重复 provider、未知模型、schema 不兼容 | 早失败，不自动重试 |
| INPUT | 非法工具参数、畸形 RPC | 结构化拒绝，不执行副作用 |
| POLICY | guard 拒绝、审批拒绝 | 可审计结果，不视为进程崩溃 |
| TRANSIENT | 429、暂时断线 | 仅由显式 retry policy 决定 |
| PROTOCOL | 流块顺序非法、缺终止块 | adapter/assembler 失败 |
| OUTCOME_UNKNOWN | 工具已分发但崩溃无结果 | 禁止盲目重试非幂等操作 |
| CORRUPTION | seq 缺口、日志校验失败 | fail-closed，拒绝恢复 |
| CANCELLED | human/parent/shutdown/policy | 保留原因，停止新工作并收敛 |
| TIMEOUT | deadline 到期 | 单独 code，不包装成普通取消或 UNKNOWN |

`RuntimeError` 至少包含稳定 code、message、retryable、phase、details（lossless JSON）、cause（仅进程内）和可序列化 record。客户端只按 code/稳定字段分支。

## Deadline 与取消合同

- 顶层把相对 timeout 转成单调时钟上的绝对 deadline；
- 下游读取剩余预算，不能每层重新获得完整 timeout；
- 多个 AbortSignal 融合时，首次取消原因获胜；
- 融合器结算后解除所有 listener；
- 已知更具体的工具失败/超时不能被晚到 abort 覆盖；
- 取消发出后仍需等待活动工作停稳。

## 测试矩阵

| 维度 | 必测行为 |
|---|---|
| brand | 不同 ID 编译期不可赋值，解析拒绝空/非法形式 |
| JSON 正常 | 任意合法值 snapshot 后往返相等 |
| JSON 非法 | undefined/BigInt/循环/非有限数/稀疏数组拒绝 |
| 不可变 | 原对象后续修改不改变 snapshot |
| 错误 | code/retryable/phase/details 过 wire 保留，cause 不泄漏 |
| 取消竞态 | 首因获胜、listener 清除、调用前取消不启动工作 |
| deadline | 多层传递剩余时间递减，不重置预算 |
| 安全 | API key/凭据不进入 message、details、record |
