# 06：模型适配、流式组装与稳定失败

## 本课定位

Agent Loop 只应看到统一消息、工具调用、usage 和终止语义；供应商的 SSE、字段、API key 和错误属于 adapter。本课先用脚本化 adapter 锁定合同，再接 DeepSeek 真路由。核心 LLM 层不内置重试，重试是可替换策略/包装层。

## 学习目标

- 定义 provider-independent request/message/chunk；
- 冻结一次调用的 provider/model/config 和 adapter 身份；
- 从任意合法分片组装文本、reasoning、多个 tool call；
- 保证每个 stream 恰好一个 terminal finish/error/aborted；
- 映射稳定失败 code，而不泄漏凭据或供应商对象；
- 分离 adapter、retry policy 和调用方 commit。

## 公共合同

### Registry 与 prepared call

`prepare/resolve` 将缺省路由解析为不可变调用，并绑定当时的精确 adapter/provider 世代。流式期间 Registry 更新不能把半个请求切到另一个 adapter。旧 adapter disposer 不能影响新世代。

### Stream chunk

至少覆盖：

- text/reasoning block start/delta/end 或等价规范；
- tool-call start/delta/end，稳定 call id/name/arguments；
- usage；
- terminal finish，携带 success/max-tokens/error/aborted 等规范原因。

协议可以与上游具体类型不同，但必须表达同等信息。finish 后任何 chunk 都是协议错误。

### Assembler

- 块身份唯一；
- delta 只能进入已开放的兼容块；
- tool call 参数片段按协议组合，最终 JSON/schema 校验属于 Tools；
- 重复 call id、未闭合块、缺 terminal、terminal 后输出被拒绝；
- 最终 AssistantMessage 恰好一次；
- 部分文本在取消时可记录 interrupted，但不能标 completed。

### 错误与重试

核心映射至少区分 authentication、rate-limit、timeout、transport、provider、protocol、invalid-request、aborted。`retryable` 是事实/建议，不等于自动重试。

若实现 retry wrapper：

- 只复用同一冻结请求；
- 在产生不可安全重放的可见/副作用结果后不重试；
- signal/deadline 贯穿所有 attempt；
- backoff 可测试，不靠真实等待；
- attempt 事件不制造多个最终 assistant message。

## 请求与 Session 顺序

```text
assemble/resolve request
→ append request/header（失败则停止）
→ adapter.stream
→ 每个规范 chunk 记录 assistant/chunk
→ assembler 得到唯一 final message
→ append assistant/message
```

API key 在调用边界解析，不进入 header、事件、错误或诊断 snapshot。

## 实现任务

1. 定义模型目录、能力、request 和 chunk；
2. 实现 adapter registry/prepared call；
3. 实现 BlockAssembler 状态机；
4. 实现 stable adapter failure 映射；
5. 用 scripted adapter 覆盖所有流场景；
6. 接 Session request header/chunk/final commit；
7. 实现显式 retry wrapper（可在独立包）；
8. 最后才实现 DeepSeek adapter 和凭据解析。

## 测试矩阵

| 场景 | 预期 |
|---|---|
| 纯文本/reasoning | 块与最终消息正确 |
| 多 tool calls 交错 | 各 call identity/arguments 完整 |
| 空成功输出 | 按合同合法空消息或明确协议错误 |
| max tokens | 唯一终止，Turn 上层可识别 |
| 重复 id/未闭合/finish 后 chunk | PROTOCOL_FAILURE |
| transport 中断 | stable failure，无伪完成消息 |
| 调用前取消 | 不调用 adapter，aborted terminal |
| 流中取消 | 部分内容 interrupted，完全停稳 |
| registry 热替换 | prepared call 仍使用旧精确 adapter |
| retryable 首次失败 | 同一冻结请求，按策略有限重试 |
| 已产出不可安全结果后失败 | 不自动重试 |
| API key 安全 | 所有事件/错误/快照中不存在 |

## 完成标准

- scripted adapter 覆盖所有矩阵且每流恰好一个 terminal；
- DeepSeek adapter 只做协议映射，不拥有 Agent 重试；
- registry 更新不影响 in-flight prepared call；
- Session 可重放最终消息和使用量；
- 无 API key 泄漏。
