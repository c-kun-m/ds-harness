## 暂停并重新设计的信号

- 为新功能不断直接修改 Agent Loop，已有 Scope/Event/Tool seam 却无法承载；
- 同一事实由 Session、Projection、领域表和 UI 各自修改；
- 工具隐藏与 dispatch Guard 读取不同 registry；
- dispose 已返回但后台任务仍写状态；
- 测试必须 sleep；
- 恢复靠猜测副作用；
- child/MCP/Workflow/PTC 直接调用工具 body；
- Prompt/Plan 被当权限；
- UI 需要内部对象才能正确显示；
- 差异账本写“之后再说”却对外声称完整。

出现任一项，回到拥有该合同的模块修正，不在上层加特判。
